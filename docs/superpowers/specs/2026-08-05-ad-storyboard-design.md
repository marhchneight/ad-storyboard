# 광고용 콘티 스토리보드 웹앱 설계 문서

- 작성일: 2026-08-05
- 상태: 승인 대기 (사용자 검토 중)

## 배경 / 목적

광고 제작을 위한 콘티(스토리보드)를 AI 이미지 생성으로 빠르게 만드는 웹 애플리케이션.
사용자는 비개발자이며, 완성 후 실제 배포(Vercel)까지 진행한다.

## 형태

- **웹 앱** (설치형 데스크톱 앱 아님). Vercel에 배포하여 URL로 접속.
- 반응형까지는 필요 없음(기본 데스크톱 브라우저 사용 가정), 다만 기본적인 사용성은 확보.

## 아키텍처

- **프론트엔드**: React + Vite, TypeScript
- **백엔드/인프라**: Supabase
  - Auth: 이메일 기반 로그인/회원가입
  - Database: 프로젝트, 컷(장면) 데이터 저장
  - Storage: 생성된 이미지 파일 저장
  - Edge Function: OpenAI 이미지 생성 API 호출을 대행 (API 키를 서버 쪽에 안전하게 보관, 클라이언트에 노출 금지)
- **AI 이미지 생성**: OpenAI 이미지 생성 API (gpt-image-1). API 키는 사용자가 직접 발급받아 Supabase Edge Function의 환경 변수(secret)로 등록.
- **배포**: Vercel

## 데이터 모델 (개략)

- `projects`
  - id, user_id, title, style (`sketch` | `animation` | `live_action`), overall_prompt, cut_count, created_at, updated_at
- `cuts`
  - id, project_id, order_index, scene_description, dialogue, camera_direction, image_url, generation_status (`idle` | `generating` | `done` | `failed`)

## 핵심 기능

### 1. 프로젝트 생성
- 제목 입력
- 스타일 선택: 스케치형 / 애니메이션형 / 실사형 (프로젝트 전체 단위 — 모든 컷에 동일 적용)
- 컷 개수 지정: 최소 2컷 이상, 사용자가 자유롭게 지정 (생성 후에도 추가/삭제 가능)
- 전체 콘셉트 프롬프트 입력 (스토리 전체 맥락 — 모든 컷 생성 시 공통으로 반영됨)

### 2. 편집 화면
- 전체 콘셉트 프롬프트: 언제든 수정 가능
- 컷 카드 목록: 각 카드에 이미지, 장면 설명, 대사/내레이션, 카메라 지시문 입력란
- 컷별 "이미지 생성" 버튼: 전체 프롬프트 + 해당 컷의 장면 설명/카메라 지시문을 조합하여 이미지 생성 요청
- 컷 추가 / 삭제 / 드래그 순서 변경
- 이미지 재생성 (다시 생성) 가능
- 컷별 독립적 생성 상태 관리 — 한 컷이 생성 중이어도 다른 컷 편집 가능

### 3. 내보내기
- PDF로 전체 스토리보드 다운로드 (이미지 + 장면설명 + 대사 + 카메라 지시문 포함)
- 컷별 이미지 개별 다운로드 (PNG)

### 4. 프로젝트 저장/관리
- 로그인 후 내 프로젝트 목록에서 언제든 다시 불러와서 수정 가능

## 오류 처리

- 이미지 생성 중: 컷 카드에 로딩 표시. 실패 시 에러 메시지 + "다시 시도" 버튼. 다른 컷 작업에는 영향 없음(컷별 독립 처리).
- 로그인 세션 만료: 로그인 화면으로 이동.
- 저장 실패: 재시도 안내.
- 컷 개수: 최소 2 미만 입력 불가하도록 검증.

## 테스트 계획

구현 완료 후 브라우저로 아래 흐름을 직접 실행하며 검증:
1. 회원가입/로그인
2. 프로젝트 생성 (스타일, 컷 개수, 전체 프롬프트)
3. 컷별 이미지 생성 (실제 AI 호출 포함)
4. 컷 추가/삭제/순서 변경
5. PDF 내보내기 / 이미지 개별 다운로드
6. 프로젝트 저장 후 재접속하여 불러오기

- 실시간 협업(동시 편집)
